# Security Policy

Pilot is a development preview. The repository does not publish a supported-release matrix or a response-time guarantee. Until a release policy is announced, security fixes target the current default branch.

## Reporting a Vulnerability

Please do not disclose credentials, personal data, or exploitable vulnerability details in a public issue, pull request, screenshot, or log.

If GitHub Private vulnerability reporting is enabled for this repository, use that private channel. If it is unavailable, contact the maintainer through the contact details on the GitHub profile and request a private reporting channel before sharing technical details. No security email address is currently published in this repository.

For ordinary, non-sensitive bugs, see the [contribution guide](CONTRIBUTING.md). For product security boundaries and privacy notes, see [Security and Privacy](docs-public/security.md).
