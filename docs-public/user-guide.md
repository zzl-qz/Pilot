# 功能与配置参考

> 最后更新：2026-11-09

本页概述工作台中的主要流程，并列出常用运行配置。首次运行请先读[首次启动指南](getting-started.md)；涉及数据、权限或远程访问时，先读[安全与隐私](security.md)。

## 项目与对话

Pilot 以项目组织工作区目录和对话。一个项目可以关联多个目录；创建任务后可切换到该项目绑定的工作区。对话保留消息、运行历史和事件记录，可归档、恢复或从历史消息分支。项目记录创建时的 Git 基线，便于理解任务开始时的仓库状态。

新建或编辑项目时，点击「选择文件夹」添加目录，在列表中移除不再需要的项，每个项目最多绑定 12 个目录。连接本机服务的桌面端使用系统目录多选框；浏览器或连接远程服务时，使用弹窗内的服务端目录浏览器逐个添加。也可展开「手动填写路径」，每行填写一个服务端绝对路径。取消选择不会清空已有目录，保存失败会保留输入以便重试。

工作台通过事件流展示模型回复、工具调用、审批和运行状态。断线后可以恢复历史事件；这不代表任务一定成功，完成状态和验证结果会分别显示。

## 执行中的任务

- **排队**：运行期间发送的新消息会作为后续独立任务保留。失败、取消或暂停时，未执行的消息不会被当作已经完成。
- **纠正**：需要改变当前任务方向时，使用“立即纠正当前”；纠正会附加到当前运行，不替换排队消息。
- **暂停与继续**：在安全步骤边界停止后续执行，保留任务要求、计划和队列。暂停不会回滚已经完成的文件修改。
- **验收**：任务可以保存约束、验收条件和证据。模型结束运行不自动等于人工验收通过；逐项核对并保存验收结果。
- **后台命令**：查看运行状态、增量日志、退出码，或停止仍受 Pilot 跟踪的命令进程。命令自身脱离进程树后不保证能被可靠清理。

系统模块边界、任务数据流和源码阅读路线见[项目技术导览](../PROJECT_TECHNICAL_GUIDE.md)。

## 审查、差异与恢复

- 以 `/review` 开头的消息进入只读审查模式；审查 run 不提供文件写入工具或子代理派发。
- “变更”面板展示工作区或当前运行差异。命令产生的改动可能不在文件写工具的检查点记录范围内。
- 消息检查点可分别恢复代码、对话，或同时恢复两者。代码恢复前会核对快照和文件状态；发现冲突时会阻止覆盖，而不是强制回滚。
- 新建 Git 分支与消息分支是不同操作；消息分支不会自动创建 Git 分支。

## 文件与成果

工作区文件工具支持浏览、读取、搜索、精确编辑和差异查看。Agent 也可以保存成果快照，用户可预览、下载并查看相关验证信息。

内置 Office 能力可以创建 XLSX、PPTX、DOCX 和 PDF，并读取文件文本进行检查。复杂排版、宏/VBA、原地覆盖已有文件、以及与 Microsoft Office 的完全排版等价都不在保证范围内。PDF 和 PPTX 可按页面渲染预览；DOCX 与 XLSX 使用结构化预览，需要核实最终排版时请用本机应用打开原文件。

## 浏览器、网络与扩展

内置浏览器供 Agent 检查页面和执行受约束的网页操作。访问公开网站、登录页面或提交表单可能涉及外部副作用，操作前应审阅具体目标和审批请求。浏览器能力不可用时，不要把无截图或无响应当作操作成功。

MCP 目前使用本机 `stdio` 启动配置中的服务器进程；添加 MCP 服务器即允许 Pilot 尝试启动该命令，应检查命令来源与参数。

## 定时任务与结果通知

定时任务需要 Pilot 后端在线。关闭后端、休眠或关机期间不会执行；恢复后，一次性任务补执行，周期计划按所选策略合并补执行一次，或跳过错过轮次。周期扫描允许一分钟内的调度延迟。暂停或取消周期计划只影响未来轮次，当前任务在定时任务列表中单独控制；旧运行退出后才允许启动下一轮。

时间按计划保存的时区计算，不随客户端或服务器的系统时区改变。夏令时回拨产生的同一本地时刻只执行第一次；夏令时前跳中不存在的周期时刻跳过，首次时间落在不存在的时刻则拒绝创建。预览、实际调度和离线恢复遵循相同规则。

桌面通知需要至少一个获准通知且开启通知的 Pilot 页面或客户端在线；Webhook 只需要后端在线。通知失败仅重试投递，不重新运行原任务。Webhook 接收器返回 2xx 表示成功，并应按 `Idempotency-Key` 去重：接收成功但回执丢失时，同一通知可能再次送达。自动投递最多尝试六次，失败后可在通知面板手动重试。

## 常用配置

默认配置位于 `pilot-server/src/main/resources/application.yaml`。本机 profile 覆盖文件 `pilot-server/src/main/resources/application-local.yaml` 已被 Git 忽略。

| 环境变量 | 用途 | 默认行为 |
| --- | --- | --- |
| `PILOT_MODEL_API_KEY` | 模型 API 密钥 | 空；可使用 Mock 模式体验界面 |
| `PILOT_MODEL_ENDPOINT` | Chat Completions 兼容端点 | OpenAI Chat Completions URL |
| `PILOT_MODEL_MODEL` | 服务商模型标识 | `gpt-4o-mini` |
| `PILOT_MODEL_TIMEOUT_SECONDS` | 单次请求总时限，覆盖响应头和完整响应体 | `900` 秒 |
| `PILOT_MODEL_IDLE_TIMEOUT_SECONDS` | 连续无数据的时限，包含等待首字；`0` 表示沿用总时限 | `600` 秒 |
| `PILOT_WORKSPACE` | 新任务默认工作区 | 启动目录 |
| `PILOT_PERMISSION_MODE` | 工具权限档位 | `AUTO` |
| `PILOT_DATA_DIR` | 会话与运行数据目录 | 仓库根目录下 `.pilot/` |
| `PILOT_RETENTION_DAYS` | 事件、快照和 trace 保留天数 | `0`，即不自动清理 |
| `PILOT_SECURITY_MODE` | 本机或令牌远程访问模式 | `local`，只允许本机回环访问 |

设置是否读取特定环境变量、支持值和覆盖优先级，请以 [application.yaml](../pilot-server/src/main/resources/application.yaml) 为准。提示词位于 `pilot-core/src/main/resources/prompts/`，可用 `PILOT_PROMPTS_DIR` 指向本机覆盖目录。

## 数据备份与恢复

在「设置 → 诊断 → 存储与备份」中可以立即备份和校验。备份会短暂暂停受管数据写入。运行中的任务或后台命令超过等待时间时，结束相关操作后重试。备份包含 SQLite、附件、任务、快照和用户 MCP 配置等受管数据。外部编辑器正在修改的文件需在备份前暂停写入。

退出 Pilot 后，用 JDK 25 执行离线恢复。命令中的 jar 路径和数据路径按实际安装位置填写。引号可保留路径中的空格。

```text
java --enable-native-access=ALL-UNNAMED -jar pilot-server.jar maintenance restore "--data-dir=目标数据目录" "--backup=备份目录"
java --enable-native-access=ALL-UNNAMED -jar pilot-server.jar maintenance restore "--data-dir=目标数据目录" "--backup=备份目录" --apply
```

第一条命令只预检。第二条将核验后的备份写入干净目录并切换，原数据和旧数据库的 WAL 文件保存在输出所示的维护目录。恢复外置数据库或附件时，显式填写 `--database=目标数据库文件`、`--attachments=目标附件目录`，并用对应配置重新启动 Pilot。切换中途退出后，可保持停服并运行 `maintenance rollback --data-dir=目标数据目录`。恢复时使用过外置路径，也将相同参数传给回滚命令。

常规备份保存 Pilot 的 worktree 登记，并在设置页列出工作区文件的收录情况。需要迁移工作区内容时，在退出 Pilot 后运行 `maintenance backup`，为每个要打包的目录添加一个 `"--workspace=目录"`。普通工作区按所选目录复制。Git 工作区保存当前提交、暂存区和工作树内容，其中未跟踪文件按 Git 忽略规则筛选。Git 子模块和冲突中的索引会提示先处理再导出。

在恢复命令中加上 `"--workspace-map=映射.json"`，映射文件是原路径到目标绝对路径的 JSON 对象。工作区导入使用新目录。Git worktree 还需给出基础仓库的新目录，用于重新建立 Git 关联和 Pilot 登记。仅迁移登记时也可把原路径映射到已有工作区。

## 当前边界

- 模型输出受模型、端点、网络和提示词影响；自动化测试不能证明真实模型任务成功率。
- 文件路径校验与权限审批不是操作系统沙箱。命令可产生本机副作用；应在可丢弃工作区内试用并保留独立备份。
- 远程访问使用单个共享令牌，没有用户、角色或会话级隔离，不适合作为直接暴露公网的服务。
- 执行历史默认保留在本机，不能把 Pilot 当作 Git、备份软件或多实例任务队列的替代品。
- Android 与电脑连接组件需要按各自指南单独构建；桌面端可运行不表示 APK、签名和移动网络路径均已验证。


### 慢速本地模型的请求时限

总时限从发出请求开始计时，收到响应头或持续心跳都不会重新计时。空闲时限限制连续没有数据的等待；默认给本地模型留出 600 秒预填充和 900 秒完整生成时间。旧的 90 秒配置现在也会限制正文读取，大上下文或推理模型可能需要调高。可设置 `PILOT_MODEL_TIMEOUT_SECONDS` 和 `PILOT_MODEL_IDLE_TIMEOUT_SECONDS` 后重启服务；数值应根据本机实测耗时调整，超时会走现有的有界重试流程，用户仍可取消。

模型普通 JSON 响应上限为 32 MiB，流式累计响应为 64 MiB，单条 SSE 行为 1,048,576 个字符。错误正文只读取前 64 KiB 后关闭连接；超大成功响应明确报错，不当作完整结果使用。模型列表和网页搜索响应上限各为 4 MiB，网页读取仍为 512 KiB。
