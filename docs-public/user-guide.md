# 功能与配置参考

> 最后更新：2026-11-24

本页概述工作台中的主要流程，并列出常用运行配置。首次运行请先读[首次启动指南](getting-started.md)；涉及数据、权限、浏览器边界或远程访问时，先读[安全与隐私](security.md)。

## 项目与对话

Pilot 以项目组织工作区目录和对话。一个项目可以关联多个目录；创建任务后可切换到该项目绑定的工作区。对话保留消息、运行历史和事件记录，可归档、恢复或从历史消息分支。项目记录创建时的 Git 基线，便于理解任务开始时的仓库状态。删除会话或整个项目时，会一并清理其文档工作台中的文档、版本、导出索引、导出文件以及对应的浏览器宿主机证据与受管会话；工作区里的源文件保持不变。

新建或编辑项目时，点击「添加文件夹」直接从系统文件夹选择器添加目录（支持一次多选多个文件夹），在列表中移除不再需要的项，每个项目最多绑定 12 个目录。浏览器没有系统选择器，或连接远程服务、原生弹框不可用时，使用弹窗内的服务端目录浏览器逐个添加，不会把路径文本当成已添加的文件夹。取消选择不会清空已有目录，保存失败会保留输入以便重试。

侧边栏支持按会话状态筛选（全部 / 进行中 / 待处理 / 未读）并展示待批准/待选择角标；顶栏提供跨会话待处理提醒条。工作台通过事件流展示模型回复、工具调用、审批和运行状态，断线后可恢复历史事件；同时提供工作区多会话协调看板，支持显式占用交接与看门狗死锁/停滞告警。按 `Cmd/Ctrl + /` 可随时打开分组快捷键速查表。

## 想法

执行任务时，输入框左侧的「想法」可以随手记下暂时不发送的内容。保存想法只写入当前会话，不会发送消息，也不会加入执行队列；AI 还在执行时同样可以新建、编辑和删除。

还没有发出第一条消息时也可以先记：这时想法先存在本机草稿里，发出第一条消息、会话建立后自动并入该会话。适合先在这里规划，再开始动手。

想法按会话独立保存：刷新页面、关闭后重新打开或切换会话再回来，已保存和改过的想法仍在，删掉的不会恢复；不同会话的想法互不影响。

点某条想法会把原文带回当前会话的输入框：输入框为空时直接填入，已有草稿时另起一行追加，原草稿和想法都不会被改写。回填后可以继续编辑，只有主动发送或加入执行队列时才会执行。

## 执行中的任务

- **分析与执行模式（`plan` / `act`）**：输入栏支持显式切换「分析（`plan`）」与「执行（`act`）」模式（快捷键 `Shift+Tab`），按消息全链路透传（含排队与续跑）。在 `plan` 模式下，后端从工具表源头剥离全部文件写入与副作用工具（包含延迟工具）并强制 `READ_ONLY` 权限门，用于只读调研和方案规划。
- **快捷命令、内置技能与内置子代理**：输入框输入 `/` 可调用 `/test`、`/fix`、`/run`、`/review`（只读审查协议）、`/browser`（浏览器任务协议）与 `/explain`，以及随包内置的开箱即用技能（`/review-code`、`/triage`、`/refactor`、`/security`、`/tests`，按项目级 > 用户级 > 内置覆盖）。多代理协作同样随包内置 3 个精选子代理角色（`explorer` 只读调研、`reviewer` 只读审查、`verifier` 编译测试验证，支持项目 `.pilot/agents/` 与用户目录同名覆盖）。
- **排队**：运行期间发送的新消息会作为后续独立任务保留，支持携带附件、执行模式（`plan`/`act`）、技能（并在排队条目直接展示 `/skill` 与「分析模式」徽标）与独立约束/验收条件。失败、取消或暂停时，未执行的消息不会被当作已经完成。队列可以单独暂停：暂停只阻止自动开始下一条，当前任务继续跑；刷新或重开后暂停状态保留，恢复时若已空闲且验收通过会立即开始队首一次。每条排队消息的约束与验收在轮到自己启动时加载成新的任务契约，不影响当前一轮。
- **附件消息**：可以只发图片或文件、不写正文；系统会补一句「请看随消息附上的文件」作为任务目标，避免空目标启动失败。
- **粘贴与拖入**：输入框支持任意类型文件；可以直接把文件拖进来（拖到窗口任意位置都算，落在输入框内时按落点插入），也可以从系统文件管理器复制后在桌面端按 Ctrl+V。同名同内容的文件重复粘贴会被忽略；文件夹不能直接添加，请压缩后再拖入。只有 PNG/JPEG/WebP/GIF 会作为图片交给模型，SVG 等按文本或文件处理。拖入完成后焦点回到输入框，可以继续编辑。默认单文件 32 MB、单条消息合计 64 MB；需要更大时用 `pilot.attachments.max-file-bytes` / `pilot.attachments.max-total-bytes` 调整后重启服务，超限文件也可以放进工作区用 @ 引用。
- **审批、提问与提醒**：文件编辑工具会在审批卡片直接展示带行数与字符上限的改动 Diff 预览，支持附原因拒绝、批量低风险批准、按站点/目录前缀一键允许规则及 `Alt+1..9` / `Alt+Y` / `Alt+N` 快捷键。支持分场景提示音、勿扰模式，以及桌面端失焦时的置顶审批悬浮提醒窗。
- **纠正**：需要改变当前任务方向时，使用“立即纠正当前”；纠正会附加到当前运行，不替换排队消息。
- **暂停、续跑与长任务韧性**：暂停在安全步骤边界停止后续执行，保留任务要求、计划和队列，不会回滚已写入的文件。遇到 HTTP 429/5xx 或网络抖动时按分级退避并识别 `Retry-After`；跨平台休眠唤醒后自动补偿退避预算并续认自持租约，瞬态断网失败支持有界自动重连续跑（永久性鉴权/参数错误不自动重连）。
- **上下文压缩、规则与长期记忆**：上下文支持手动/自动两段式摘要压缩（可填写重点保留 `focus` 并在暖前缀会话中复用主对话前缀缓存）。项目规则支持根目录 `AGENTS.md` 与 `.pilot/rules` 标准 Glob 路径匹配；外置长期记忆以 `MEMORY.md` 索引保存正式条目，模型调用 `remember` 仅写入待审草稿、`read_memory` 支持免密钥本地多词分词与字段加权排序检索（兼顾中英文简称与长短语召回），用户在「设置 → 记忆」审阅发布或手动编辑。
- **验收**：任务可以保存约束、验收条件和证据。模型结束运行不自动等于人工验收通过；逐项核对并保存验收结果。
- **后台命令**：查看运行状态、增量日志、退出码，或停止仍受 Pilot 跟踪的命令进程。命令自身脱离进程树后不保证能被可靠清理。

系统模块边界、任务数据流和源码阅读路线见[项目技术导览](../PROJECT_TECHNICAL_GUIDE.md)。

## 审查、差异与恢复

- 以 `/review` 开头的消息进入只读审查模式；审查 run 不提供文件写入工具或子代理派发。
- “变更”面板展示工作区或当前运行差异，支持按勾选文件暂存并直接提交（经 `git commit --only -F -` 安全传递 UTF-8 提交说明、不跳过钩子）、本地确定性草拟中文提交说明（无需模型 Key）以及折叠查看当前分支近期提交历史。命令产生的改动可能不在文件写工具的检查点记录范围内。
- 代码与仓库分析工具：`code_symbol` 支持单文件结构大纲与跨文件符号定义搜索（支持 `query`、`path`、`glob`、`kind` 过滤与相关性排序）；`code_diagnostics` 默认作为核心工具可见（非代码仓库自动隐藏），支持 Maven（`test-compile` 多模块）、Gradle、TypeScript（含 monorepo 子目录与本地 `node_modules/.bin/tsc`）、Go、Python（pyright/ruff）与 Rust（cargo check）行级诊断；并行只读 Git 工具（`git_status`、`git_diff`、`git_log`）支持在主代理、分析模式与子代理中并发查看仓库状态、暂存/未暂存差异与提交历史。
- 文件变更容错与跨平台操作：`edit_file` 优先精确匹配，未命中时按行尾空白与统一相对缩进偏移做唯一兜底并自动对齐缩进（多处命中仍严格拒绝）；独立 `delete_file` 与 `move_file` 工具提供跨平台删除/重命名并接入运行快照回滚。
- 消息检查点可分别恢复代码、对话，或同时恢复两者。代码恢复前会核对快照和文件状态；发现冲突时会阻止覆盖，而不是强制回滚。
- 新建 Git 分支与消息分支是不同操作；消息分支不会自动创建 Git 分支。

## 文件与成果

工作区文件工具支持浏览、读取、搜索、精确编辑和差异查看；工作区文件树支持文件名快速过滤、Git 改动徽标（`M`/`A`/`D`）及右键菜单（「用系统默认应用打开」「在文件夹中显示」「复制相对路径」）。Agent 也可以保存成果快照，用户可预览、下载并查看相关验证信息。

工作台内置跨平台通用文件预览引擎（零外部进程依赖）：支持代码语法高亮、PDF/图片/音视频流式预览、DOCX/XLSX/PPTX 结构化内容与公式结果解析，以及 `.zip`/`.jar`/`.war`/`.epub` 压缩包目录清单。内置 `office` 工具可创建 XLSX、PPTX、DOCX 和 PDF 并读回校验；复杂排版、宏/VBA、原地覆盖已有文件以及与 Microsoft Office 的完全排版等价都不在保证范围内，需要核实最终排版时请用本机应用打开原文件。

## 浏览器、网络与扩展

内置浏览器供 Agent 验收本机 Web 应用或执行受控的网页任务，提供两类入口：直接调用 `browser` 工具，或通过 `/browser` 命令与独立隔离的浏览器子代理 `browser_agent` 执行（子代理拥有独立上下文与步数上限，禁用 `evaluate` 与文件/Shell 工具，返回宿主机 `<browser_host_facts>`、最新截图附件与自动过程录像路径）。

- **精准交互与复杂页面支持**：支持多层同源 `iframe` 穿透与开放 Shadow DOM 快照（跨域 `iframe` 安全跳过）、交互前自动居中滚动与双向遮挡探测、HTML5/坐标拖拽（`drag`）、无 DOM 语义控件与 `<canvas>` 的视觉坐标 `(x, y)` 兜底、原生 `alert`/`confirm`/`prompt` 预设与历史回查（`dialog`）、非原生按钮触发的动态 `filechooser` 上传，以及最多 50 步的连续批量动作（`batch`）。
- **Take Control 控制锁与人工接管**：智能体自动操控期间，页面、Web 镜像面板、输入框停靠条（`BrowserControlDock`）与 Electron 桌面端同步进入常驻蓝色控制锁定态；点击任一处红色「停止控制 (Stop)」会绕过串行队列即时抢占中止 `batch`/`wait` 并锁定后续驱动请求，直至用户显式恢复。遇到登录、MFA、人机验证或支付门控时通过 `handoff` 暂停并移交用户操作（支付页自动交互硬拦截），恢复后自动失效旧 `ref` 并要求重新 `snapshot`。
- **过程录像与交互式回放**：支持跨平台无外部二进制依赖的过程录像 `record`（产出 `.replay.json`，自动跳过敏感支付/认证页画面帧）。证据面板支持对截图或录像任意暂停帧拖拽框选并插入带像素坐标与比例的定位反馈到对话输入框，录像弹窗还提供倍速播放（`0.5x`/`1x`/`2x`）、进度条拖动、步骤时间轴点击跳帧与目标高亮盒/光标同步叠加。
- **边界提示**：访问公开网站、登录页面或提交表单涉及外部副作用，操作前应审阅审批请求与目标站点；下载与上传受大小、路径与危险内容检查约束（详见[安全与隐私](security.md#浏览器隐私与安全边界)）。浏览器能力不可用时，不要把无截图或无响应当作操作成功。

- **联网搜索与网页读取（`web_search` / `web_fetch`）**：
  - `web_search` 默认零付费密钥即可开箱可用，也支持按需接入第三方 API：本机/自建 **SearXNG** 托管配置已升级至 v4 免密钥引擎池（覆盖 `bing`/`360search`/`yahoo`/`brave`/`duckduckgo`/`quark`/`startpage`/`mojeek`/`wikipedia`、`duckduckgo news`/`bing news`、`baidu kaifa`/`github`/`stackoverflow`/`mdn`/`pypi`/`npm`/`hackernews`/`huggingface`/`crates.io`/`docker hub` 以及 `arxiv`/`semantic scholar`/`openalex`/`crossref`/`pubmed`，旧版 Pilot 托管配置及遗留托管进程会在启动或重启时自动备份并升级，自定义配置不受影响）；开启自动回退后，主源失败、0 结果或 SearXNG 命中偏少时会自动回退/补齐免密钥官方公开只读 API（Wikipedia 中/英、GitHub、StackOverflow、Hacker News、arXiv、OpenAlex）。如有需要，也可在「设置 → 搜索」或环境变量中按需选配博查 Bocha、Tavily、Brave Search、Serper (Google) 或 Exa。支持 `category`（`general`/`news`/`it`/`science`）、`time_range`（`day`/`week`/`month`/`year`）、`language`、`site`（严格站点域名过滤）、`page` 与 `count` 参数，自动对 URL 去重、结合查询词相关性重排并透出上游引擎异常诊断。
  - 在「设置 → 搜索」可直接切换提供商、保存或清除 API 密钥（只写不读）、配置出网代理（本机回环自动直连）、同步配置并重启本机 SearXNG，以及不落盘发起实时测试搜索。
  - `web_fetch` 支持读取 HTML、纯文本、Markdown、JSON 与 XML，自动识别 UTF-8 / GBK / GB18030 等编码并优先提取 `<article>`/`<main>` 正文，最多安全跟随 5 次公网重定向（每一跳都重新执行本机/内网/保留地址 SSRF 校验并拦截重定向循环）。

MCP 同时支持本机 `stdio` 进程与远程 **Streamable HTTP / SSE** 传输（支持 `Mcp-Session-Id`、JSON 与 `text/event-stream` 响应及传统 SSE 405 自动回退，禁止跨站重定向泄露认证头）。添加服务器即允许 Pilot 尝试启动命令或连接远端地址，应检查命令来源、URL 与请求头。未信任的服务器首次启动/连接会请求批准；审批卡上的「批准并信任服务器」会记住当前配置指纹（stdio 钉住命令/参数/环境变量，远程钉住传输方式/URL/请求头），之后不再逐次询问，首次观测后还会钉住它声明的工具定义，工具定义变化会重新要求审批。设置 → MCP 提供常用免 Key 模板（Filesystem、Fetch、Git、Memory、Sequential Thinking、Context7）一键填入，支持表单添加、编辑已有用户级配置（保留未改动的既有密钥）、粘贴 JSON 导入、删除与撤销信任。详细的信任边界见[设计说明](design-mcp-trust.md)。

## 模型预设、故障转移与免密钥语音输入

- **免密钥本地服务与多模型预设**：API Key 留空时不再发送空认证头，原生兼容 Ollama、LM Studio、llama.cpp、vLLM 等本机免密钥服务（设置页提供一键填入快捷按钮）。在「设置 → 模型 → 模型预设」可保存、编辑、删除和一键切换多套预设（API Key 只存后端、界面仅显示掩码），支持在设置页或输入框模型菜单（`ModelPicker`）中切换。
- **自动故障转移（备用预设）**：可将任意模型预设标记为「备用」（如「免费云端接口 → 本机 Ollama 兜底」）。主模型遇到 429 限流重试失败、额度耗尽/402/401/403 或连接断连时，当前运行会自动无缝切换至备用预设继续完成并在界面提示，不改写全局主配置，且不会对 400 参数错误、上下文超限或主动取消盲目转移。
- **语音输入**：在「设置 → 模型 → 语音输入」支持三种方式：`自动`、`浏览器免密钥`（基于浏览器原生 Web Speech API，无需任何 API Key，不支持该 API 的浏览器/桌面端会给出明确提示）与 `转写接口`（兼容 OpenAI 转写协议及免密钥本机 `whisper.cpp` `/inference` 与 `faster-whisper` 回环端点）。自动模式下若远端接口鉴权失败且当前浏览器支持 Web Speech，会提供一键「改用浏览器免密钥识别」回退入口。

## 定时任务与结果通知

定时任务需要 Pilot 后端在线。关闭后端、休眠或关机期间不会执行；恢复后，一次性任务补执行，周期计划按所选策略合并补执行一次，或跳过错过轮次。周期扫描允许一分钟内的调度延迟。暂停或取消周期计划只影响未来轮次，当前任务在定时任务列表中单独控制；旧运行退出后才允许启动下一轮。

时间按计划保存的时区计算，不随客户端或服务器的系统时区改变。夏令时回拨产生的同一本地时刻只执行第一次；夏令时前跳中不存在的周期时刻跳过，首次时间落在不存在的时刻则拒绝创建。预览、实际调度和离线恢复遵循相同规则。

桌面通知需要至少一个获准通知且开启通知的 Pilot 页面或客户端在线；Webhook 只需要后端在线。通知失败仅重试投递，不重新运行原任务。Webhook 接收器返回 2xx 表示成功，并应按 `Idempotency-Key` 去重：接收成功但回执丢失时，同一通知可能再次送达。自动投递最多尝试六次，失败后可在通知面板手动重试。

### 按端点与模型配置请求时限

总时限从发出请求开始计时，收到响应头或持续心跳都不会重新计时。无数据等待时限包含首字之前的等待。默认总时限 900 秒、无数据等待 600 秒；这些都是上限，模型提前完成会立即返回。时限不按模型品牌、量化方式或能力强弱自动猜测，本地模型和云端复杂推理都可能需要较长时间。

在模型设置中的「请求时限、计价与缓存」里，可为当前已保存的端点与模型分别设置时限，无需重启。总时限允许 1–86400 整数秒，无数据等待允许 0–86400 整数秒；0 表示跟随总时限，实际无数据等待不会超过总时限。留空继承服务端默认值，界面会显示已保存的有效值。切换到其他端点或模型使用它自己的配置，切换回来恢复原值；已经开始的请求保留原时限。

服务端默认值仍可通过 `PILOT_MODEL_TIMEOUT_SECONDS` 和 `PILOT_MODEL_IDLE_TIMEOUT_SECONDS` 设置，修改环境变量后需要重启；已有模型专属设置优先。超时走现有的有界重试流程，用户仍可取消。较短时限可以更早发现无响应，应根据端点的实际耗时设置，不能把正常长推理误当故障。

模型普通 JSON 响应上限为 32 MiB，流式累计响应为 64 MiB，单条 SSE 行为 1,048,576 个字符。错误正文只读取前 64 KiB 后关闭连接；超大成功响应明确报错，不当作完整结果使用。模型列表和网页搜索响应上限各为 4 MiB，网页读取上限为 2 MiB。

## 数据备份、诊断与恢复

在「设置 → 诊断 → 存储与备份」中可以立即备份和校验，也可点击一键导出脱敏诊断包（对应接口 `GET /api/diagnostics/export`，支持可选 `?sessionId=`，汇总版本、系统/Java 信息、启动恢复状态、最近最多 200 条脱敏会话事件与 50 条失败/重试请求记录，标记 `sanitized=true` 并经 `Redaction` 与 `SecretScrubber` 双重脱敏）。备份会短暂暂停受管数据写入。运行中的任务或后台命令超过等待时间时，结束相关操作后重试。备份包含 SQLite、附件、任务、快照和用户 MCP 配置等受管数据。外部编辑器正在修改的文件需在备份前暂停写入。

退出 Pilot 后，用 JDK 25 执行离线恢复。命令中的 jar 路径和数据路径按实际安装位置填写。引号可保留路径中的空格。

```text
java --enable-native-access=ALL-UNNAMED -jar pilot-server.jar maintenance restore "--data-dir=目标数据目录" "--backup=备份目录"
java --enable-native-access=ALL-UNNAMED -jar pilot-server.jar maintenance restore "--data-dir=目标数据目录" "--backup=备份目录" --apply
```

第一条命令只预检。第二条将核验后的备份写入干净目录并切换，原数据和旧数据库的 WAL 文件保存在输出所示的维护目录。恢复外置数据库或附件时，显式填写 `--database=目标数据库文件`、`--attachments=目标附件目录`，并用对应配置重新启动 Pilot。切换中途退出后，可保持停服并运行 `maintenance rollback --data-dir=目标数据目录`。恢复时使用过外置路径，也将相同参数传给回滚命令。

常规备份保存 Pilot 的 worktree 登记，并在设置页列出工作区文件的收录情况。需要迁移工作区内容时，在退出 Pilot 后运行 `maintenance backup`，为每个要打包的目录添加一个 `"--workspace=目录"`。普通工作区按所选目录复制。Git 工作区保存当前提交、暂存区和工作树内容，其中未跟踪文件按 Git 忽略规则筛选。Git 子模块和冲突中的索引会提示先处理再导出。

在恢复命令中加上 `"--workspace-map=映射.json"`，映射文件是原路径到目标绝对路径的 JSON 对象。工作区导入使用新目录。Git worktree 还需给出基础仓库的新目录，用于重新建立 Git 关联和 Pilot 登记。仅迁移登记时也可把原路径映射到已有工作区。

## 当前边界

- 模型输出受模型、端点、网络和提示词影响；自动化测试不能证明真实模型任务成功率。
- 文件路径校验、权限审批与本机文件系统沙箱不等同于多租户虚拟机隔离。命令可产生本机副作用；应在可丢弃工作区内试用并保留独立备份。
- 远程访问使用单个共享令牌，没有用户、角色或会话级隔离，不适合作为直接暴露公网的服务。
- 执行历史默认保留在本机，不能把 Pilot 当作 Git、备份软件或多实例任务队列的替代品。
- Android、Electron 桌面与三平台自包含发行包需要按各自指南分别验收；单平台或无头浏览器测试通过不表示 Windows / Linux 物理桌面及真机路径均已实机验证。
