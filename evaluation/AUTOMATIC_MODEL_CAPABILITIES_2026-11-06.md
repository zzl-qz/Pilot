# 模型与中转站能力自动发现（2026-11-06）

默认只填写服务地址、密钥和模型。程序在启动、保存模型配置或首次实际使用时自动启动后台发现；设置页面不需要检测按钮。未完成验证时保留 Pilot 工具，不能用模型名称、模型自述、模型列表中的 `tools` 参数或 HTTP 200 代替真实能力证据。

## 已接通范围

- OpenAI Responses 格式的服务端网页搜索。
- Anthropic Messages 格式的服务端网页搜索、网页获取。支持以这些协议转发的中转站与私有模型别名，不按中转域名或模型名称继承官方权限。
- 自有网页工具始终保留在运行时注册表。原生客户端只在实际请求序列化时隐藏被替代的函数定义；明确拒绝原生工具后，同一轮恢复本地定义继续完成任务。
- 主代理和多智能体的请求计量、预算与拒绝处理传递同一个降级入口。失败尝试和降级请求分别经过原有请求边界，不在客户端内部偷偷重放。
- 已知聊天协议路由不可用时有界选择其他已适配协议；鉴权、余额、限流、断流与普通参数错误不触发协议盲重放。
- 保留自定义聊天完整路径、带前缀的 API、根级协议路径及查询参数。实现使用 Java HTTP/URI 与 Node 标准路径/进程接口，验证入口有 Windows `java.exe` 分支。

本轮自动路由覆盖的是上述搜索与获取能力。Excel、通用代码执行、项目构建、文件上传与产物下载尚未新增厂商托管适配，继续由现有执行工具完成；不能因声明有代码执行就移除项目测试或文件工具。非上述格式的私有协议、网关私有工具类型仍按未知处理。验证证明当前链路能完成该能力，不证明中转内部一定由原厂执行。

## 自动发现与验证

1. 从用户配置的同一站点、同一路径前缀查询模型元数据，只读取目标模型。元数据用于选择验证顺序；`supported_parameters: ["tools"]` 不证明服务端代执行能力。
2. 无需用户干预，使用固定公开任务验证已适配协议。探测不读取或发送会话、工作区、附件；不接受元数据提供的第三方探测地址，不跟随重定向。
3. Responses 需返回完成的 `web_search_call`；Messages 需有名称对应的 `server_tool_use` 和匹配调用 ID 的成功结果。纯文本声称成功、未配对结果和错误结果均不启用能力。
4. 只有已验证的能力才加入服务端请求。当前任务不等待后台 HTTP 验证；首次业务请求遇到明确的协议路由拒绝，也有有界自动选择与正常失败出口。
5. 后台最多同时验证 2 个配置，同一配置合并并发请求。单个 HTTP 完整请求含响应体限时 6 秒、响应体上限 1 MiB；超时取消实际 HTTP future。每轮至多 1 次元数据 GET 和 3 次小型 POST；每次输出上限 128 tokens，Responses `max_tool_calls=1`，Messages `max_uses=1`。

验证会产生少量服务商请求和可能的工具费用，界面显示该事实与本轮探测请求数；输入/输出用量保存在能力报告。这里的探测用量与业务请求用量分开，不能把它当成免费操作或完整供应商账单。

## 缓存与手动出口

- 缓存键由完整服务地址、模型、凭证指纹和协议提示共同计算；不存明文密钥，也不跨账号复用验证结果。
- 最多 64 个配置，使用一个有界设置项落盘，应用重启可复用未到期结果。成功保留 6 小时，明确不支持保留 30 分钟，暂时未知保留 5 分钟；到期在后续正常访问中自动重新验证。
- 后台迟到结果不能覆盖运行时拒绝或其他配置的结果。重新验证成功后，已有客户端可以恢复使用原生能力。
- 设置中的 `local`、`openai-responses`、`anthropic-messages` 仍是高级出口。选定协议只限定验证协议，不把未验证能力直接标记为支持。设置仍按端点/模型保存；切换密钥保留该模型的选择，换模型使用该模型自己的设置。
- 可通过 `pilot.model.capability-discovery.enabled=false` 全局关闭后台探测，默认开启。关闭时不发送验证请求，任务保留自有工具。
- 页面自动更新检测状态；不会覆盖用户正在编辑但尚未保存的报价与兼容选项。状态刷新失败后会自动重试，卸载后停止计时器。

## 验证与复跑

JDK 25 下构建与检查：

```sh
sh mvnw -B -ntp spotless:apply
sh mvnw -B -ntp verify
node scripts/verify-model-capabilities.mjs
node pilot-web/frontend/scripts/request-usage-smoke.mjs
```

Windows 使用 `.\mvnw.cmd` 替换 `sh mvnw`。后台验收脚本需要当前后台 Jar，并以 `JAVA_HOME` 指定 Java 25。它启动随机端口的隔离后台和本机假中转；从进程启动开始验证自动触发，随后核对模型/密钥变更、缓存、无密钥回显和手动本地模式。它不调用真实厂商、不操作个人后台，也不需要手机。

本轮验证日志位于本机 `/tmp/pilot-auto-*.log`，不提交运行产物。Surefire 默认关闭测试 JVM 的外部后台探测；独立发现测试直接使用本机网关，真实 Jar 验收显式开启默认自动发现，分别覆盖纯测试与生产装配路径。三平台 verify CI 增加了该隔离后台入口；配置已更新，未在远程运行。
