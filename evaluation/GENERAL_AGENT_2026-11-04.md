## 正常、失败与边界

- 成果：重复保存幂等；原文件修改后快照不变；SQLite 重启后可读；快照篡改或缺失失败；会话归属检查；越界路径、外部符号链接、空文件、不支持格式、超限文件拒绝；中文文件名与空格目录可用。
- 来源：仅成功配对的 `web_fetch` 回执计为已读取；失败回执、模型自述和单独提供的网址不计；保留 URL 中的编码路径与查询参数；拒绝非 HTTP/HTTPS 及带凭据地址。
- 预览：长文本截断；不可提取 PDF 及 Office 格式给出下载替代；前端展示下载失败与重试入口，不伪造成功。
- 技能：提案不激活；接受后可从技能目录读取；新技能撤回不留下无效空目录；更新旧技能后可恢复原始 CRLF 字节；拒绝不写入；过期版本、后续编辑及恢复冲突不会被覆盖。
- 恢复：意图已保存但文件未写时回到可重试状态；文件已写但状态未提交时核对指纹后收敛；外部改动转为冲突，不静默重放。
- 兼容：拒绝 Windows 设备保留名、非法名称和描述换行；拒绝无法无损恢复的旧技能 UTF-8 内容；技能关闭时拒绝写入；清理记录保留原文件与已接受技能。
- 登录：错误令牌、异源、请求限流均明确拒绝；公开登录页不包含令牌或会话数据；首页旧令牌 URL 清理；SSE 令牌兼容；注销后访问 API 返回 401。
- 界面：1440 / 768 / 390 宽度检查，无页面或成果面板横向溢出；手机主要操作至少 44px；来源状态、接受/拒绝/撤回、冲突、加载失败、重试、会话切换、键盘焦点返回均实测。

## 视觉复核

使用 `design-taste-frontend` 应用界面规则，沿用原有中性主题。新增文件静态检查 0 FAIL / 0 WARN；登录页浏览器检查 0 FAIL / 1 WARN（桌面居中登录表单两侧留白，保留为单一输入任务的布局）。人工查看桌面/手机截图后修正了按钮被全局样式压小、顶部文字换行与窄屏侧面板未铺满的问题；详情页补上焦点进入与返回。成果面板暗色/浅色截图均复核。

## 固定任务与能力边界

`evaluation/harness/general/tasks.json` 含 4 组非编码任务。原始夹具 4/4 验收失败；参考结果通过；改坏输出并篡改工作区测试后仍失败。说明验收有分辨力，不说明真实模型已完成这些任务。该任务集的验收关注结构化内容与输入保留，不评判开放世界事实、报告文风，也不替代成果登记的 API 测试。

本轮真实 Jar 测试只输入任务草稿，没有发送模型请求。此前真实模型筛查的 `insufficient` 结论未被更改。Office 文件只提供保存/下载，尚无原生 Office 排版编辑与预览。

实际桌面验证在 macOS；Linux 验证发生在 Docker 容器。Windows/Linux 桌面客户端、iOS/Android 真机、跨独立局域网和公网代理部署未实测。已做标准路径/进程接口、保留名校验、原子移动替代分支、浏览器下载与响应式兼容处理，不将本机通过等同于全平台通过。

构建仍有既有 Vite 大块产物提醒，不影响本轮构建；它不属于已解决问题。
