# 模型探测与选择回归 · 2026-11-04

## 原因与修复

设置页调用探测接口后只更新提示文本，未渲染可选列表。输入区虽然有列表组件，却仍读取已配置的全局候选，未接入这一次探测响应，并且只显示前 12 个模型。

两个入口现在共用本地表单探测状态和模型列表组件：

- 探测结果直接显示为可选行，数量按有效、去重后的 ID 计算。
- 点击或方向键选择会填写模型名称，点击“保存”后才修改配置；仍允许手动输入。
- 长列表提供搜索与滚动，不再截去第 12 个之后的模型。选中行有标记，键盘 Tab 顺序只包含一个列表入口，弹窗正确包含焦点。
- 端点、密钥改变或表单关闭后丢弃过时响应，不把临时端点的探测结果写进全局配置。探测中防止重复点击；空列表、失败和错误格式分别反馈，保留用户输入的模型名。
- 结果初次出现时使首个模型可见；1440 / 768 / 390 窗口下无横向溢出。共享 DOM / CSS、标准键盘和滚动接口，未新增系统专用代码。

## 证据

- Web 单元测试 264 项通过，增加模型 ID 去重、无效条目和数量一致性覆盖。
- `test:models` 在 Chrome 和真实 Electron 主进程中通过，使用隔离 HTTP 接口与真实 App / store / api：6 个可选模型、30 个模型及最后一项、搜索无结果、方向键选择、显式保存、空结果、503、畸形数据、端点与密钥变更、旧响应晚到、关闭重开、Tab 焦点，以及三个窗口宽度。
- `test:interaction` 的输入、审阅、消息队列、侧边对话、设置、文件树和焦点回归通过；既有工作台回归加入“探测 → 实际点击模型 → 名称填写”断言，避免只有数量提示也算通过。
- 后端 `SettingsApiTest` 9 项通过，包含只读探测、端点换算、保存与密钥保留 / 清除契约。
- Maven `-pl pilot-server -am package -DskipTests` 构建成功，包含实际前端构建；本轮未改 Java 生产代码。

使用 macOS 本机 Chrome 和真实 Electron；Windows / Linux 共用实现，未做两系统实机。没有请求用户配置的真实模型服务或修改实际模型 / 密钥。Android App 的全局服务配置权限沿用现有边界。

最终专项截图临时目录为 `pilot-model-discovery-13KbF0`，已检查桌面宽屏与窄屏的实际主题截图。运行服务需加载新前端资源；旧 Jar 运行时需重启后台，再关闭设置窗口并重新载入工作台。

## 保存反馈补充验收

用户反馈保存有请求但界面没有响应。此前验收确认了配置更新，漏查保存反馈是否在弹窗内可见：原实现仅通过工作台通知显示结果，通知位于设置遮罩后；设置页按钮也缺少保存中状态。

修复设置页和输入区两个入口：

- 保存按钮显示“保存中…”，两个入口共用写入锁，关闭、重开也不能并发重复保存或清除 Key。模型名、端点、Key 与模型选择在写入期间禁用。
- 操作旁直接显示持久的成功 / 失败反馈，错误使用 alert，普通结果使用 status；较矮窗口下反馈滚入可见区域，不改变键盘焦点。
- 直接应用 PUT / DELETE 返回的完整设置，更新模型候选和已加载能力页中的当前模型，不等待额外 GET。保存前启动的旧设置读取不能覆盖新配置。
- 保存失败保留输入和 Key，恢复按钮以便重试；成功清空明文 Key 并更新已保存掩码。清除 Key 不丢弃未保存的模型名和端点。空模型名不能提交。
- 输入区成功保存后关闭菜单，失败保留菜单并显示具体错误；旧表单完成请求的回调不会关闭后来重开的菜单。

扩充 `test:models` 的真实 App / store / HTTP 测试，覆盖慢请求、防重复、关闭重开、503、断网、畸形响应、真实 20 秒超时和重试、密钥清空 / 掩码、清除失败 / 成功、未保存草稿保留、旧 GET 晚到。截图增加 768 × 480 的低高度窗口。接口全部为隔离的本地测试接口，未修改用户配置或调用付费模型服务。

兼容范围仍是 Web / Electron 共用 React、DOM 和 CSS，未新增操作系统专用接口。Android 远程端沿用电脑端已保存模型，本次不新增远程修改服务凭据入口，也未运行 Android 真机验收。

补充验收结果：264 项 Web 单元测试通过；扩展后的 `test:models` 和完整 `test:interaction` 均在 macOS Chrome / 真实 Electron 通过；后端 `SettingsApiTest` 9 项通过，包含实际前端构建的 Maven package 成功。Windows / Linux 未做实机验证。专项最终截图目录 `pilot-model-discovery-hYqyZn`，已检查 Electron 窄屏和低高度窗口；日志 `/tmp/pilot-model-save-ui-verified.log`、`/tmp/pilot-model-save-interaction-final.log`、`/tmp/pilot-model-save-package-final.log`。
