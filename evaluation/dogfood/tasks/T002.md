- **级别**：L1（单模块已知根因）

- **类型**：明确需求（带路径）
- **预期改动范围**：
  - `pilot-server/src/main/java/com/pilot/server/runtime/BundledRuntime.java`
  - 对应单元测试（如 `BundledRuntimeTest.java`）

## 冻结任务原话（原样下发给 Pilot）

```text
在独立 git worktree 里显式设置 `PILOT_DATA_DIR` 启动 `pilot-server` 时，我发现 `pilot-server/src/main/java/com/pilot/server/runtime/BundledRuntime.java` 会无视 `PILOT_DATA_DIR`，直接往当前 worktree 下的 `.pilot/runtime/python` 重复下载一套 Python 3.12。

请修改 `BundledRuntime`：
1. 注入 `PilotDataDir`，当用户显式配置了 `pilot.data.dir` / `PILOT_DATA_DIR` 时，内置运行时根目录优先使用 `dataDir.file("runtime")`；
2. 未显式配置 `pilot.data.dir` 时，保持现有在源码树落到仓库根 `.pilot/runtime`、否则当前目录 `.pilot/runtime` 的兼容行为；
3. 补齐对应单元测试验证路径解析逻辑（不要在单测里真的联网下载 Python），并跑通相关测试与格式/质量检查。

注意：只改本任务相关文件，不要执行 `git commit`、`git push` 或 `git remote`。
```

## 独立验收清单

1. **正确性（0–2）**：显式 `pilot.data.dir` 时 `runtimeRoot()` 命中 `dataDir.file("runtime")`，未显式配置时保留原有兼容行为，且不破坏现有无参/单参构造调用方（如存在）。
2. **测试（0–2）**：离线确定性单元测试覆盖显式与未显式两种分支，不触发联网下载。
3. **范围（0–2）**：改动收口在 `BundledRuntime` 及对应测试。
4. **规范（0–2）**：全量 `pilot-core,pilot-server` `test` + `spotless:check` + `checkstyle:check` + `quality-gate.mjs` 0 新增违例。
5. **汇报（0–2）**：答复与 diff 及实际测试结果完全一致。
