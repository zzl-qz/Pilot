- **级别**：L1（单点根因，无路径定位）
- **来源**：实测产品缺陷 `P-003`（Stage 1.1 `java -jar pilot-server-0.0.1-SNAPSHOT.jar` 启动日志实测复现）
- **类型**：**只给目标不给路径**
- **预期改动范围**：
  - `pilot-server/src/main/java/com/pilot/server/frontend/FrontendDepsPrompt.java`
  - `pilot-server/src/test/java/com/pilot/server/frontend/FrontendDepsPromptTest.java`

## 冻结任务原话（原样下发给 Pilot）

```text
我刚刚用 Maven 打好 `pilot-server-0.0.1-SNAPSHOT.jar`，然后在项目目录里执行 `java -jar pilot-server/target/pilot-server-0.0.1-SNAPSHOT.jar` 启动服务，结果启动日志里居然还弹出了那个「Pilot 启动检查：前端依赖 pilot-web/frontend，输入 2 后回车即更新，20 秒内无输入则直接启动」，硬卡了 20 秒才开始起 Spring Boot。

按代码原本设计，这个提示不是应该只在 IDE 直接运行或 `mvn spring-boot:run` 的开发态才问、打包后的可执行 jar 启动时直接静默跳过吗？请你查一下为什么打包 jar 启动还是触发了这个询问，彻底修好（注意跨平台路径和 Spring Boot 4 嵌套 jar URL 形态），并补齐针对性的单元测试验证 jar 模式跳过、classes 开发态仍生效，同时保持现有单测和格式/质量检查全部通过。

注意：只改本任务相关文件，不要执行 `git commit`、`git push` 或 `git remote`。
```
