# 提示词实验候选

`p2-flow/` 保存 2026-11-03 流程优化 P2 的完整冻结提示词，用于复现与对照评测。
内容与该次评测输入逐文件一致，包括其内部 README；该 README 描述候选规则，
不表示这些规则已经成为默认行为。

P2 尝试合并重复规则、明确问答与执行边界、按任务复杂度规划、依据失败原因恢复，
并在上下文压缩时保留用户纠正、授权、验证证据和下一步。真实评测仍未通过推广门禁，
不能据此宣称任务成功率或效率已全面改善。默认 classpath 提示词保留原版本，
P2 只供明确选择的实验使用。结果和局限见[流程评测报告](../FLOW_EVAL_2026-11-03.md)。

## 使用前提

- 在隔离的评测工作区或已明确接受实验行为的环境中使用，保持模型、工具、任务和验收条件可比较。
- 将 `PILOT_PROMPTS_DIR` 设置为本目录下 `p2-flow` 的绝对路径，再启动 Pilot 服务；
  也可以使用系统属性 `pilot.prompts.dir`。路径由实际部署位置确定，不依赖特定操作系统。
- 该目录包含完整模板；按同名覆盖 classpath，缺失模板仍会回落到默认值。
  为保留可复现性，不修改冻结候选；后续实验应复制到新的版本目录。
- 以实际工具记录和独立验收判断结果，模型最终说明不能替代验收证据。

## 回滚

取消服务启动环境中的 `PILOT_PROMPTS_DIR`；如果还配置了 `pilot.prompts.dir`，也同时移除。
重启服务后恢复默认 classpath 提示词。无需改动或删除候选目录。
