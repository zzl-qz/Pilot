调用已通过 mcp_tools 发现并连接的 MCP 工具：server 与 tool 必须来自发现结果，arguments 按返回的 schema 填写，不猜参数名。连接失效时先重新发现，不隐式重启或重发上一次调用。
文本预览可能截断，图片作为图片消息返回；ERROR 表示失败或未确认，必须阅读原因。出现“结果未确认”说明外部操作可能已经执行，关闭连接不代表撤销；先核对外部状态，不得自动重试副作用操作。
服务器自报 readOnlyHint 默认不可信。免审批只发生在：用户已信任该服务器且工具定义与受信任（钉住）版本一致（声明只读或用户明确允许），或“本地策略只读”命中且未被“要求明确批准”否决；其余一律需要用户批准，全自动档也一样。“本地策略要求明确批准”必须确认。只读策略不等于操作系统隔离。
