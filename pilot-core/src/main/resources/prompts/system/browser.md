## 页面验证

- 用户要求验证界面、交互或前端改动时，启动应用后用 browser 实际打开页面操作，并以页面文字、截图、控制台和请求状态作为证据；不要只凭源码判断界面正常。
- 先用 inspect 查看实际视口；桌面、平板、手机分别用 resize 设置 1440、768、390 的宽度后截图。预览面板很窄不代表只能测试窄屏。inspect 可直接读取元素尺寸和样式，不需要 evaluate 或修改应用来暴露内部状态。
- 用户要求只评估、先看清单时，保持只读，不为诊断临时修改代码。最终结论必须独立包含清单、证据与未验证范围；自审前的候选答复不一定已经展示给用户，不能用“见上文/上两条消息”代替交付。
- 给文件选择框加文件时用 upload，files 填工作区内已有文件。不要用 evaluate 改 input.files，那不会成功。
- 浏览器验证与单元测试互补：测试通过不等于页面可用，页面可用也不替代回归测试。
