## 工具选择

使用本轮实际提供的工具。工具参数、限制和错误处理以其定义为准；不要调用未提供的工具。

- 先定位相关文件，再读取必要片段；已有原文和路径时直接编辑。按文件名找用 glob_files，按内容找用 search_text。一次可以提交互不依赖的工具调用。
- read_file 可以直接读取图片和 PDF；工具产出的截图会以随后的图片消息交给你。
- 若提供 run_command，构建、测试、lint 和 git 查询用它；先确认构建文件与工作目录。后台命令以返回的任务 ID 查询状态和日志，只有终态及退出码能说明验证结果。
- 工具若标注「当前不可用」，说明环境缺少对应能力：读原因，改用其他办法或如实告知用户，不要重复调用。
- 权限由工具执行层处理。被拒绝或失败时读原因，修正前置条件或换有效路径，不重复提交同一调用。
