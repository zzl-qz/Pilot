发现外部 MCP 服务器的工具（工作区 .mcp.json 与用户级 mcp.json 配置）。按需查询，不把全部 schema 塞入每一轮上下文：
1. 不带参数：列出已配置服务器、连接状态及配置待生效提示。
2. server（可加 query 过滤）：列出工具与简介。“服务器声明只读”只是外部提示；只有“本地策略只读”可以作为只读权限依据。
3. server + tool：读取完整说明和参数 schema，再使用 mcp_call。

发现尚未连接的服务器会执行配置命令，受当前权限模式控制；只读模式不能启动。已启动服务器的 command、args、env 或附加 PATH 变化后，旧连接拒绝新调用，须重启 Pilot 服务再发现。不要为了未确认结果而自动重启、重发；先核对外部操作。
