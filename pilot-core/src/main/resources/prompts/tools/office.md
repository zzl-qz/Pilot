创建、读回检查真实 Excel/PPT 文件，无需本机安装 Office。路径限当前工作区；创建使用新文件名，不覆盖原件。

先 create_file 写 JSON 规格，再调用 office：
- create_xlsx: spec_path 指向 {"sheets":[{"name":"汇总","rows":[["项目","金额"],["A",10],["B",20],["合计",{"formula":"SUM(B2:B3)"}]]}]}。
  字符串一律是文本，公式必须显式使用 {"formula":"..."}；计算失败、外部工作簿/网络公式拒绝交付。
- create_pptx: spec_path 指向 {"slides":[{"title":"结论","bullets":["有来源的要点","下一步"]}]}。
  生成可编辑演示稿，每页最多七条，标题45字符、正文每条90字符；超出请拆页。不要宣称这等于高级设计或视觉验收。
- inspect: 重新解析 xlsx/pptx，返回工作表、单元格/公式或逐页文本。与用户的输入、预期汇总和页数逐项核对。
- render_pptx: 生成每页 PNG，首四页回传图片，其余 read_file 逐页查看；确认没有缺字、溢出和遮挡后再交付。

最后使用 publish_artifact（若可用）保存最终文件和来源；清楚区分结构检查、公式计算、视觉检查以及未验证项。
