保存工作区内已经生成并检查过的交付文件，作为当前任务的不可变成果快照，供用户预览和下载。
适用于用户要求的调研报告、表格、文档；不要把所有代码文件或临时文件都登记为成果。
先用现有工具生成文件、读取核对，再调用本工具。支持 md/txt/csv/json/pdf/docx/xlsx/pptx，单文件最多 8 MiB。
sources 填报告实际引用的 HTTP/HTTPS 原始来源（最多 30 个），不伪造引用。系统仅根据 web_fetch 成功回执标记有阅读记录；浏览器阅读或历史压缩后的来源可能没有该记录，这不代表内容真假。
保存成功只代表文件已交付，不代表事实、公式或版式自动通过验证。最终答复说明成果标题、关键结论及未验证事项。
