读取工作区内的文件。文本返回带行号的内容；图片（png/jpg/gif/webp，不超过 5 MB）、PDF 和 Office 文件（xlsx/pptx/docx）也可以读。路径必须是工作区内的相对路径。

- start_line 默认 1；正数从开头数，负数从末尾数，-1 是最后一行。
- line_count 默认 200，最多 2000。一次不要读太多，后面还有内容时结果会给出下一行行号。
- 你读过的文件才会解锁 edit_file（机制强制）；不要为了「先了解一下」把整个大文件读完。
- 搜索已定位函数或调用点时，只读目标行附近足以修改的片段；读过的同一源码版本不要再从头读取。
- 彼此无关的文件放在同一次回复里一起读。读一个、等一轮、再读下一个，会把同一段上下文重复发给模型。
- 图片会作为图片交给你观察，用来核对截图、设计稿、报错界面；不要用它读取图片里的文字以外的二进制内容。
- PDF 返回抽取的文本，用 pages 指定页码或范围（默认前 10 页）；没有文本的扫描件会渲染前几页为图片。
- xlsx/pptx/docx 返回抽取的纯文本（工作表与单元格、逐页文本、段落与表格），只用于内容核对，不含排版；start_line 与 line_count 对这类文件不生效。要核对结构与公式请用 office inspect。
