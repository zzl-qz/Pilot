把一条值得跨会话记住的条目写入外置记忆候选区（不会修改工作区代码）。

闭合分类（`type`）：
- `user`：用户技术背景、角色与长期协作风格
- `feedback`：用户明确表达的偏好、行为纠正，或已验证有效的非常规做法（正反都要记）
- `project`：代码中查不到的项目决策背景、为什么选 A 不选 B、未完成迁移约束
- `reference`：外部系统链接或资源入口（如看板、文档、监控地址）

编写规则：
1. 尽量补充 `why`（为什么这样做 / 适用条件）；时间必须写成绝对日期（`YYYY-MM-DD`），禁止“昨天/下周”。
2. 严禁记录可以从源码、`git log`、构建文件实时查到的事实（如文件结构、版本号、API 列表），也不要记一次性任务细节或未授权敏感凭据。
3. 写入的是候选区，只有用户在「设置 → 记忆」审阅采纳后才会注入后续会话；不确定要不要记时，宁可先不记。
