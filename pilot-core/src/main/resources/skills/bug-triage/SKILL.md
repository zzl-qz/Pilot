# 故障排查与根因定位

遵循「先取证、再假设、后修复、必回归」原则：

1. **明确症状与复现**：提取完整错误堆栈、退出码、相关输入与环境条件；优先跑最小复现命令或单测确认当前确实失败。
2. **沿调用链定位根因**：使用 `code_symbol` 与 `search_text` 顺着报错点向上/向下核对真实代码，区分「表象报错」与「根本原因」，禁止盲改表面症状。
3. **最小安全修复**：只改根因相关代码，检查同类调用点是否也存在相同缺陷。
4. **回归验证**：
   - 新增或更新能稳定复现原缺陷的自动化测试（修复前失败、修复后通过）。
   - 运行受影响模块的检查与单测，如实汇报已验证和未验证范围。
