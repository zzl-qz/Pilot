# 代码与配置安全体检

围绕以下高风险面逐项核对，基于真实代码给出证据与修复方案：

1. **凭据与敏感信息**：检查是否存在硬编码密钥/Token、日志/异常/`toString()` 或接口响应泄露明文凭据。
2. **路径与文件系统边界**：检查用户输入路径是否经过规范化与根目录边界校验，是否防范 `..` 遍历与符号链接逃逸。
3. **命令与参数安全**：检查子进程调用是否避免 shell 拼接、是否正确使用 `--` / `:(literal)` / stdin 传递不可信文本。
4. **网络与外部输入**：检查远程 URL 协议白名单、重定向凭据泄露风险、响应体积与超时上限。
5. **权限与信任边界**：检查关键写操作/高危工具是否受权限策略保护，降级策略是否保持 fail-closed。
