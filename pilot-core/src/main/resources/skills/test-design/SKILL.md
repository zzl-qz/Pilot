# 自动化测试设计与补齐

先读清被测实现与项目现有测试风格，再按四个维度补齐高信噪比用例：

1. **主流程（Happy Path）**：验证核心输入输出与持久化/状态变更契约。
2. **失败与异常路径**：空参数、非法格式、不存在的资源、外部依赖失败或超时是否返回明确且可行动的错误。
3. **边界与安全条件**：空集合、超长/截断上限、特殊字符（中文/引号/空格）、越界路径与并发竞争。
4. **跨平台兼容**：不依赖本机绝对路径或特定系统命令，使用临时目录与本地回环桩服务确保在 Windows/macOS/Linux 均可稳定通过。

完成后实际运行新增与关联测试，确保全部通过后再汇报。
