                设置
                
        
                外观偏好存在本机浏览器，模型与权限由服务端保存并立即生效。
                
      
                
      
    
                
    
                
      
                
        
        
        
        
        
        
        
      
                
      
                
        
                
          
                主题
                
          
                选择界面明暗；「跟随系统」会随操作系统外观自动切换。
                
          
                
          
                强调色
                
          
                用于按钮、选中态和运行状态的高亮色。
                
          
                
        
                

        
                
          
                模型
                
          
                留空表示保持当前值，保存后下一次模型请求生效；填好端点与密钥后可点「获取模型」拉取清单。
