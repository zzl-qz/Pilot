    今天让 Pilot 做什么？

    在本地工作区里读代码、跑工具、改文件。能力范围由左下角的权限模式决定。

    CtrlN 新任务 · @ 引用文件 · / 快捷指令 · Esc 停止

    模型

         Enter 发送 · 拖入文件 · @ 文件 · / 命令

    连接后这里会按序号显示 run / tool / approval 事件。

        选择工作区

        Pilot 只能读写你选中的这个目录，所有工具路径都被限制在它内部。

          新建项目

          项目用来归拢同一套代码下的对话，可以绑定多个文件夹；每个对话只用其中一个，随时可换。

          文件夹

              ↑↓ 选择 · Enter 执行 · Esc 关闭

              设置

              外观偏好存在本机浏览器，模型与权限由服务端保存并立即生效。

              主题

              选择界面明暗；「跟随系统」会随操作系统外观自动切换。

              强调色

              用于按钮、选中态和运行状态的高亮色。

              模型

              留空表示保持当前值，保存后下一次模型请求生效。

              权限模式

              决定工具能做什么：从只读到全放行，切换后立即生效。
