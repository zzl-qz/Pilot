// Dry-run local cleanup above pre-compact threshold; preserve hot cache prefix if compaction is needed
boolean compactFirst = !compactCircuitOpen && !inBackoff(messages, overhead)
    && usage(messages, charsLimit, tokensLimit, overhead) >= PRE_COMPACT_RATIO
    && !localCleanupSuffices(messages, tokensLimit, charsLimit, overhead, boundary);

Dual budgets & hysteresis. Token limits track provider windows while char caps bound heap; history stays append-only under 80% to preserve Prompt Caching.

Dry-run before mutation. Prevents destructive pruning right before summarization so warm prefixes survive.

// Resolve deepest existing ancestor via NOFOLLOW_LINKS + toRealPath, then re-attach pending suffix
Path existing = candidate;

Deepest existing ancestor. Handles brand-new file creation, Windows 8.3 short paths, and dangling external symlinks cleanly.

Security

Four permission tiers by reversibility

File writes can be rolled back via snapshots; shell command side effects cannot.

ModeReadWriteCommandBest For
READ_ONLY AllowDenyDeny Code reading & architecture analysis (also via plan or /review)
ASK AllowApproveApprove First trials or sensitive repos—inspect every diff & command
AUTO_EDIT AllowAllowApprove Trusted edits & local browser checks while gating shell commands
AUTODefault AllowAllowAllow (redlines enforced) Daily workflows (still blocks root/home deletion, force-pushes & key leaks)

macOS (Seatbelt) and Linux (bubblewrap) enable OS filesystem sandboxing for main-session commands by default, but local sandboxes are not multi-tenant VM isolation. Try ASK or READ_ONLY in a disposable repo first.

Quick Start

Running locally in three steps

First launch provisions JDK 25, Node 22, and desktop dependencies into a private cache and verifies the build before starting.

  1. 1

    Clone the repository

    git clone https://github.com/zzl-qz/Pilot.git
  2. 2

    Start Pilot

    bash start.sh
    .\start.cmd

    Serves http://localhost:9999 (and opens Electron desktop when available). Switch from AUTO to ASK or READ_ONLY for your first run.

  3. 3

    Connect a model

    # OpenAI Chat / Responses, Anthropic Messages, or keyless Ollama/vLLM
PILOT_MODEL_API_KEY=your-api-key
PILOT_MODEL_ENDPOINT=https://api.openai.com/v1/chat/completions
PILOT_MODEL_MODEL=gpt-4o-mini
PILOT_WORKSPACE=/path/to/test-repo

    No key yet? Use Mock mode in Model Settings to explore the workbench UI.

Known Boundaries

What Pilot does not promise

Explicit limits make verification verdicts trustworthy.

Not VM isolation

Seatbelt/bubblewrap constrain local writes, and Windows requires an optional restricted runner; untrusted code still belongs in a container or VM.

Pre-send token estimation

Provider usage is recorded verbatim on responses, while pre-flight budgets use conservative estimators that may compact slightly early.

Lossy compaction

Folded turns retain two-stage handoff summaries; key source regions may be re-read on demand.

Command side effects

Checkpoints cover Pilot file tools only—arbitrary shell side effects cannot be rolled back automatically.

No silent conflict merges

Divergent multi-agent proposals or manual edits always pause for human resolution.

Single-machine & shared token

Built for individual local workflows; remote mode uses a single bearer token and should never be exposed raw to the public internet.
