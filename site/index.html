双预算与滞回冷却。token 预算对齐模型输入窗口，字符上限独立作内存护栏；80% 以下保持严格只追加，减少打穿 Prompt Cache。

安全

四档权限，按可逆性分级

不是按「危险程度」一刀切：文件改动有快照可回滚，命令的副作用没有等价物。

档位读工具写文件执行命令适用场景
READ_ONLY 放行拒绝拒绝 只读分析（也可通过 plan 模式或 /review 触发）
ASK 放行逐次审批逐次审批 初次试用或重要仓库，每步看 Diff 确认
AUTO_EDIT 放行直接执行逐次审批 信任编辑与本机浏览器交互，仍看住命令
AUTO默认 放行直接执行常规放行（高危红线拦截/确认） 日常开发（仍强制拦删根/家目录、强推受保护分支与凭证外发）

macOS（Seatbelt）与 Linux（bubblewrap）对主会话命令默认启用文件系统沙箱，但本地沙箱与权限策略仍不等同于多租户虚拟机隔离。首次试用请先切换到 ASK / READ_ONLY 并在可丢弃工作区验证。

已知边界

它现在还做不到什么

如实记录，比含糊其辞更有用。

不是虚拟机级沙箱

macOS/Linux 默认启用文件系统沙箱，Windows 需独立配置受限运行器；跨机器与不可信代码仍建议容器或独立隔离环境。

token 预算含估算

响应会记录服务端真实 usage 与费用，但发包前预算控制采用字符/token 估算，可能略早于真实 tokenizer 触发压缩。

摘要不可逆

被折叠的对话细节只剩两段式交接摘要，续跑时关键源码可能需要按需复读。

命令副作用不可回退

检查点只覆盖写文件工具记录的路径，sed -i 或外部构建产物不在自动回退范围。

多智能体不自动合并

冲突与结论分歧一律交人裁决，不绕过审阅静默覆盖工作区。

单机与共享令牌

面向个人单机使用，没有多租户账号或集群调度；远程访问使用单共享令牌，不建议直接暴露公网。
